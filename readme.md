# 🎓 MERN Learning Management System (LMS)

A **full-stack Learning Management System (LMS)** built using the **MERN stack**, designed to manage courses, users, quizzes, and learning progress with **secure authentication** and **role-based access control**.

This project demonstrates real-world **web development**, **authentication flows**, and **scalable backend design** suitable for production-grade applications.

## 🔧 Features

- 👥 **Role-Based Access Control**
  - Separate dashboards for **Students**, **Teachers**, and **Admins**
  - Secure authorization for each role

- 🔐 **Authentication & Security**
  - JWT-based authentication
  - Password encryption using `bcrypt`
  - Email verification for user accounts

- 📚 **Course & Content Management**
  - Gated chapters with **progress-based unlocking**
  - Structured course flow for better learning experience

- 📝 **Quizzes & Evaluation**
  - Quiz participation and evaluation
  - Course completion tracking

- 📊 **Progress Tracking**
  - Tracks learner progress across courses
  - Completion status visibility

- 🎨 **Modern UI**
  - Clean, responsive user interface
  - Dashboard-based layouts for easy navigation
